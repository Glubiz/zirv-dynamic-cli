# vt100 dashboard spike — verdict: GO

**Date:** 2026-08-13 · **Gate for:** `docs/superpowers/plans/2026-08-13-zirv-dashboard.md` Wave 1+

## Result

- **Human probe (real interactive claude in a sub-region, separate Windows
  Terminal):** rendering "looks good" — TUI legible, colors sane, no
  cursor escapes into the sidebar region. Input forwarding worked
  (typing reached the child).
- **Automated check:** `vt_spike --check` passes against a 543 KB raw
  ConPTY capture of the real session (`tests/fixtures/claude-session.raw`,
  recorded via `--record`; **gitignored** — a raw capture of a personal
  session, tests must skip when absent).
- **Bug found by the probe:** Ctrl+Q didn't quit. Cause: on Windows the
  key can arrive as the raw DC1 byte `Char('\x11')` with no CONTROL
  modifier flag (VT input mode) rather than `Char('q')+CONTROL`.
  `is_quit` now matches both shapes plus `Char('Q')+CONTROL`. Carry this
  into the dashboard's prefix-key matching (Task 5): **match control keys
  by both modifier-flag and raw-control-byte representations** —
  `Ctrl+A` may arrive as `Char('\x01')`.
