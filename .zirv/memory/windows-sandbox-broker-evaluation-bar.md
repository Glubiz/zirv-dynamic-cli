Native Windows Claude Code has no OS sandbox; containment there rests on the PreToolUse safety hook alone, an accepted standing gap. Brokers Landstrip, Arapuca and Microsoft MXC were evaluated and rejected (2026-08-24) as mandatory invisible brokers: none proves one identical security contract across Windows/macOS/Linux, MXC is preview-only. The bar set for a broker: adversarial three-OS tests, fail-closed behaviour, preserved approval presentation, an auditable effective policy.
